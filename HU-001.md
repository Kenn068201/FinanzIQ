**MÓDULO 1**: ROL USUARIO FINAL

**HU-001:** Registro de Usuario Final  

•	**Título Corto**: Registrador cuenta de usuario final  

•	**Módulo:** Autenticación y Cuentas  

•	**Prioridad:** Alta | **Estimación:** 3 puntos de historia  

• **Estado:** Finalizada   

• **Sprint:** 1


**1. REDACCIÓN ESTÁNDAR**

•	**COMO** Usuario final de FinanzIQ

•	**QUIERO** crear una cuenta en la aplicación ingresando mis datos personales (nombre, correo y contraseña)  

•	**PARA** acceder de forma privada a mis herramientas de gestión financiera personal

**2. CONTEXTO Y DETALLES DE SOPORTE**

**•	Descripción/Notas:** Requiere encriptación de contraseña (Bcrypt/Argon2).  
Debe enviar correo de confirmación.  

Validar formato de correo electrónico y fortaleza de contraseña.  
**3. CRITERIOS DE ACEPTACIÓN (BDD)**

•	Escenario 1 (Camino Feliz):  
o	DADO QUE el usuario no tiene una cuenta activa y está en la pantalla de registro
o	CUANDO ingresa un correo válido, segura contraseña y presiona "Registrarse"
o	ENTONCES el sistema crea el usuario, envía correo de verificación y redirige al inicio de sesión con el mensaje "Cuenta creada con éxito".

•	Escenario 2 (Caso límite):
o	DADO QUE el usuario intenta registrarse con un correo electrónico que ya existe en la base de datos
o	CUANDO presiona "Registrarse"
o	ENTONCES el sistema bloquea el registro y muestra la alerta "El correo electrónico ya está registrado".
