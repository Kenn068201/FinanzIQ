**HU-002:** Inicio de Sesión  

•	Título Corto: Iniciar sesión en la plataforma
•	Épica / Módulo: Autenticación y Cuentas
•	Prioridad: Alta | Estimación: 3 puntos de historia
• Estado: Finalizada

1. REDACCIÓN ESTÁNDAR
•	COMO Usuario final de FinanzIQ 
•	QUIERO autenticarme con mi correo y contraseña
•	PARA acceder a mi información financiera guardada de manera segura

3. CONTEXTO Y DETALLES DE SOPORTE
•	Descripción/Notas: Generación de JWT (JSON Web Token) con tiempo de vencimiento. Permitir recuperación de contraseña vía correo.

5. CRITERIOS DE ACEPTACIÓN (BDD)
 
•	Escenario 1 (Camino Feliz):
o	DADO QUE el usuario ingresa sus credenciales correctas
o	CUANDO presiona "Iniciar Sesión"
o	ENTONCES el sistema responde con un token de sesión válida y muestra el panel principal (Dashboard).

•	Escenario 2 (Caso límite):
o	DADO QUE el usuario ingresa una contraseña incorrecta tres veces seguidas
o	CUANDO intenta presionar "Iniciar Sesión"
o	ENTONCES el sistema bloquea temporalmente el intento por 5 minutos y muestra "Credenciales incorrectas".

• Must Have (Debe Tener)
• Emisor de JWT con vencimiento
• Bloqueo temporal por fallos

• Should Have (Debería Tener)
• Recuperación de contraseña
• Duración de token variable

• Could Have (Podría Tener)
• Opción de mostrar/ocultar contraseña
• Historial de accesos

• Won´t Have (No tendrá por ahora)
• Autenticación biométrica
• Recordar datos
